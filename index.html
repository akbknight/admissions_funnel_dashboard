Enrollment analytics dashboard for Kogod School of Business. Tracks every stage — Started → Submitted → Completed → Admitted — across MBA, Online, and Specialized Masters programs. Compares Fall 2026 vs Fall 2025 with domestic/international breakdowns.

YoY Enrollment Comparison
Side-by-side Fall 2026 vs Fall 2025 metrics for every funnel stage — total, domestic, and international headcounts with delta indicators.
Deposit Pacing
Day-of-year pacing chart tracking net new deposits across enrollment cycles. Surfaces early-cycle acceleration or lag versus prior year.
Funnel Volume Chart
Horizontal funnel visualization comparing term-over-term volume at each stage. Built with Plotly, rendered inside Streamlit.
Sidebar Filters
Program and term filters in an always-visible sidebar. All charts and metrics respond instantly via DuckDB in-memory queries.

Tech Stack

Python Streamlit DuckDB Plotly Pandas HTML/CSS (custom Streamlit theme)

Run Locally

# Clone and install
git clone https://github.com/akbknight/admissions_funnel_dashboard.git
cd admissions_funnel_dashboard
pip install streamlit pandas duckdb plotly
# Launch dashboard
streamlit run app.py

# Opens at http://localhost:8501
